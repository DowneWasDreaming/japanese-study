# 木漏れ日 · 个人日语学习室

中文界面的本地个人学习网站：React + TypeScript + Express + Node.js 内置 SQLite。学习数据保存在本机；AI 通过官方 **Sign in with ChatGPT / ChatGPT plan usage** 授权调用 OpenAI。没有 API Key 配置或备用计费路径。

公开源码仓库：[DowneWasDreaming/japanese-study](https://github.com/DowneWasDreaming/japanese-study)。仓库保存源代码、测试与运行说明；个人学习数据和登录凭据在各自电脑上保存。

## 日常使用：双击启动

**当前 Windows 电脑已经安装依赖并完成构建，直接在资源管理器中使用即可，不需要打开终端。**

1. 打开此项目文件夹 `japanese_study`。
2. 双击根目录的 **`启动日语学习.vbs`**。服务在后台运行，就绪后自动用默认浏览器打开网站。通常只需要几秒；首次安装或代码更新后构建可能更久。
3. 学习结束可以直接关闭浏览器；后台服务继续运行。要完全关闭服务，双击 **`停止日语学习.vbs`**。再次学习时重新双击启动文件。

重复双击启动会打开已运行的网站，不重复开启服务。启动器核对项目目录及运行实例；停止入口仅关闭此目录启动器所拥有的服务。需要等待当前请求时，停止最多给予 5 秒，随后完成数据库关闭；未完成的 AI 评分可在下次启动后重试。正常启动和停止没有命令窗口；错误会显示对话框。

如果想在桌面使用：右键 `启动日语学习.vbs`，选择“显示更多选项 → 发送到 → 桌面快捷方式”。请创建快捷方式，保留原文件在项目文件夹内。

启动入口优先使用本机 Codex 捆绑的 Node.js，也会查找 PATH 或常规安装目录中的 Node.js 24+。缺少依赖时会尝试通过已安装的 pnpm/npm 自动安装，缺少页面构建或前端代码更新时会自动构建。无需管理员权限。运行记录和日志位于 `.local/runtime/`，不进入 Git 或学习备份。若 Windows 禁用了脚本宿主，需要启用系统的 Windows Script Host，或使用下面的开发者启动方法。

## 安装与启动（开发者）

需要 **Node.js 24+** 和 **pnpm 11+**。数据库使用 Node 内置 `node:sqlite`，不需要额外安装数据库服务。

```powershell
pnpm install --frozen-lockfile
pnpm run init
pnpm dev
```

浏览器打开 **http://127.0.0.1:3210**。开发模式通过同一本地后端提供 Vite 页面；仅监听 `127.0.0.1`。首次启动自动执行无损迁移和原创种子初始化，`init` 可以重复运行。它不会清空已有学习记录。

生产运行仍是本机运行：

```powershell
pnpm build
pnpm start
```

```powershell
pnpm check
pnpm test
pnpm audit:files
```

Windows 可使用 `./scripts/start.ps1 -Install`；使用 `-Production` 时构建并启动生产模式。此脚本优先使用本机 pnpm/npm，也支持当前 Codex 环境已捆绑的 pnpm。代码不依赖该机器的绝对路径。

默认无需 `.env`。配置示例见 `.env.example`。要加载自定义环境文件，可用 Node 的 `--env-file=.env` 运行 `node --env-file=.env --import tsx server/index.ts`，生产模式在末尾加 `--production`。修改端口时网站地址和本次 OAuth 回调 URI 会同步调整。

## ChatGPT 登录及真实接入验证

1. 启动网站后进入“连接与设置”。点击 **Continue with ChatGPT**，由浏览器打开 OpenAI 官方授权页面。
2. 亲自登录自己的 ChatGPT 账号，选择工作区，并批准套餐使用权限。服务端接收回调并验证身份。
3. 页面会分别显示“已连接”和“套餐使用已授权”。仅有身份登录成功还不能请求模型。
4. 刷新模型列表，选择该账号实际可用的模型。列表来自官方接口，不写死型号。
5. 点击“生成一道题并验证”。这将获取模型、通过官方 Responses 端点完成真实流式调用、校验题目结构，并把一道 N5 题保存为 SQLite 试卷。打开这份练习完成作答和评分。

首次注册使用 `dynamic_agent_client`；回调返回的真实 `client_id` 与注册记录关联并保存，以供重新授权复用。安装有稳定的、不包含个人身份的 host ID。每次授权重新生成 PKCE、state 和 nonce。回调为 `http://127.0.0.1:3210/auth/callback`（更换端口只改变端口），授权和换取凭据时使用完全一致的 URI。

身份令牌通过 OpenAI JWKS 验证签名、issuer、audience、有效期和 nonce。以令牌响应实际授予的 `chatgpt.tokens.use.direct` 范围判断套餐权限。令牌保留在后端受保护目录；刷新串行化，轮换后的凭据原子保存。退出连接不删除学习数据。重新连接可以复用注册，新增账号的授权记录独立保存。

此流程无需单独购买 API 额度，但底层依然使用 OAuth 和模型 HTTP 请求。应用不读取 Codex 或其他应用的登录文件。AI 所需学习文本会发给 OpenAI；**本地存储不代表完全离线**。

账号或工作区是否符合接入条件，由 OpenAI 实际授权和调用结果决定。用量入口打开 [ChatGPT Settings → Usage](https://chatgpt.com/settings/usage)，不会用 token 数估算剩余百分比、恢复时间或人民币费用。达到额度限制时请查看该页面，不会自动切换计费。

## 学习与考试

内置原创词汇、语法、五十音和示例题，包含 JLPT N5～N1 参考等级。离线可浏览、搜索、收藏、加入生词本，并在常规判卷模式下完成客观题练习。等级仅供学习参考；原创和 AI 练习均不是官方试题，也不提供水平认证。

单词提供读音、词性、常见含义、搭配及双语例句；语法提供含义、接续、场景、语气、口语/书面差异、易错点和相似语法。句子解析和连续追问保存为本地对话；同条件讲解有缓存，可主动重新生成。

出卷可选难度、题量、题型、类别、知识点、生词、错题或薄弱点，支持练习/考试模式。题型为单选、填空、阅读理解、中译日、日译中及指定语法造句。完整试卷和评分标准在校验通过后持久化；AI 无效结构只允许有限修复。内置题池有容量限制，不能满足选项时会提示调整，避免伪造题目。

AI 出卷默认参考最近的相关历史题目，并在保存前对照**全部仍保留的试卷**和本套题目查重。查重依据题型、题干和阅读材料，统一 Unicode NFC 与空白格式；更换题目 ID、选项顺序或答案解释不能绕过。发现重复时最多重新生成一次完整试卷，仍重复则提示失败，整套不保存。并发出卷排队执行，后一次能够看到前一次刚保存的题目。模型收到的历史摘要最多 30 题、12,000 字符，不发送历史答案或成绩。

同一知识点允许通过不同句子、语境和阅读材料复习。程序能够拒绝上述文本重复，但无法保证所有不同措辞的题目在语义上完全不同；题目范围过窄时可扩大知识点或类别。内置题池和主动错题重练保留重复训练的行为。删除历史试卷后，该试卷不再参与出卷查重。

“我的积累 → 知识点”记录每个知识点的等级、已出题数量、已评阅次数、正确率、最近出题和练习时间，可搜索、筛选等级并点击“针对练习”。这些记录从 SQLite 的试卷快照及成绩计算，重启后保留；同一道题中重复的知识点标签只计一次，未评阅的题不会算作答错。相同名称的不同等级分别统计。这是题目关联和学习统计，目前不包含手写知识点笔记。

答题自动保存到 SQLite，刷新后继续。练习模式可逐题反馈，考试模式在交卷前由服务端隐藏答案、解析和评分标准。保存后的试卷版本用于评分。

“开始练习”可以独立选择题目来源和**判卷方式**：

| 判卷方式 | 单选、阅读选择、填空 | 翻译、造句 |
| --- | --- | --- |
| 常规判卷（默认） | 本机按试卷保存的答案判分；填空匹配参考及可接受答案 | ChatGPT 按标准评阅 |
| 全部由 AI 判卷 | ChatGPT 根据完整题目、选项、阅读材料及评分标准评阅 | ChatGPT 按标准评阅 |

内置题库的题目也能选择 AI 判卷。AI 会收到洗牌后实际选中的选项 ID 和文本；单选及阅读选择仍只接受零分或满分，非法选项不能得分。AI 填空评阅接受合理等价表述，可以给部分分，但仍须区分会改变含义的假名、长音和词形。翻译和造句接受合理不同表达。未作答题在本机记零分，不请求模型。

判卷方式随试卷保存在 SQLite 和学习备份中，刷新、重启和恢复后保持。旧试卷和缺少该字段的旧备份默认使用常规判卷。答题页中**从未评分、未交卷的草稿**可以修改判卷方式；开始任何一次评分（包括失败或待完成）后锁定，避免一份试卷中途变换评分规则。已有成绩不重新计算，需要改变方式时可创建新练习，或重新练习后在首次评分前切换。

AI 判卷需要 ChatGPT 套餐授权及正常网络。每道非空回答单独请求一次模型，题量较大时判卷时间和套餐使用会增加；本地只统计次数，不再设置次数上限。选择 AI 判卷不会在失败时自动切换为本机判分。

重复交卷有并发保护与持久化结果，不会重复计分。AI 评阅请求失败时已完成的评分仍保留，失败部分标为“部分评分待完成”，仅重试这些题。没有授权时需要 AI 评阅的题目无法完成评分，不会被当成零分。可以报告题目疑问；报告保存在本机，作为学习内容纠错记录。

错题按等级、题型、知识点筛选并重新练习。统计来自真实本地答题：单选、阅读选择及本机判分的填空满分记为正确；AI 填空、翻译和造句达到该题分值的 80% 记为正确，尚未完成评分的题不进入正确率。复习推荐依据错误次数和上次练习时间，可查看推荐原因。查看历史、普通页面、常规客观判分和缓存命中的讲解不调用模型。

## 做题时标记词句，交卷后解析

题干、选项、阅读材料里遇到不懂的词句，即使不是这道题的考点，也可以加入本卷的待解析标记：

1. 用鼠标选中同一处原文中的词或句子，点击出现的“标记待解析”。可以重复操作，添加多处标记；原文会高亮显示。
2. 手机或键盘操作可点击“添加标记”，选择题目和原文位置，输入或粘贴原文片段。如果同样的片段出现多次，再选择具体的那一处。
3. 标记立即保存到本机，切题、刷新或重启后仍保留。可展开“待解析词句”核对或移除。每题最多 8 处，整卷最多 40 处，每处最多 500 个字符；重叠片段可以分别标记，完全相同的位置不会重复添加。
4. 交卷确认里可勾选“交卷后解析标记”。评分保存后，再单独请求 AI 解析；尚未授权 ChatGPT 套餐时先保留标记，连接后可回来继续。
5. 已交卷页面的“标记词句解析”显示读音、当前语境中的意思、语法或成分分析、例句及记忆提示。也可以在旧试卷上继续添加标记，再解析新增内容。已完成结果直接复用，“仅重试失败”只重试失败部分。

同一道题的多处标记合并为一次模型请求，解析会结合保存的题干、阅读材料、选项和标记位置，而不只按孤立单词查询。每道涉及未完成标记的题目请求一次 AI，使用已授权套餐额度；本地计数只作统计。保存标记和阅读已保存解析不调用模型。

标记解析要求先交卷；练习模式只查看单题反馈也不会提前解析。解析状态与成绩分开保存，解析失败或中断可以重试，原有分数和已完成解析保留。从“学习记录”打开原卷可以再次查看。重新练习会创建新试卷，新卷从空标记开始。

## 数据、凭据和备份

默认位置（相对于项目目录）：

| 内容 | 位置 |
| --- | --- |
| 学习 SQLite 数据库（含词句标记与解析） | `.local/data/study.sqlite` |
| SQLite WAL/SHM | 数据库同目录 |
| 本机 host ID、授权注册和令牌 | `.local/credentials/` |
| 删除前、恢复前自动备份 | `.local/data/backups/` |
| 下载的导出 | 浏览器下载位置 |

可以通过 `STUDY_DATA_DIR` 和 `STUDY_CREDENTIAL_DIR` 自定义位置。凭据目录必须与学习目录分开。凭据目录由后端限制文件权限；在 Windows 使用当前用户 ACL，在 Unix 使用仅用户可读写权限。如果权限设置失败，授权流程应报错，不能声称凭据受到保护。

在设置页导出版本化 JSON 学习备份，包含试卷、草稿、成绩、词句标记与解析、失败诊断历史、错题、生词、收藏、对话和讲解缓存，不包含认证凭据。当前导出格式为版本 3，也能恢复旧版本 1、2（缺少的词句标记或诊断表按空记录处理，旧失败仅补录仍保留的最后一次快照）。考试模式仍在答题或评分时，导出会提示先完成考试，避免备份绕过答案公开时机。恢复前严格验证结构、外键、标记原文位置、解析状态、诊断字段及脱敏状态、成绩与考试状态，先自动备份当前学习数据，再事务恢复。恢复失败回滚，备份中尚未完成的请求恢复为可重试状态并记录中断。请优先通过导出/恢复搬迁学习数据；不要在服务运行时只复制 `.sqlite` 而忽略 WAL。凭据应通过重新登录恢复。

“学习记录”可以删除单份试卷，“句子解析”可以删除选中的历史对话。“连接与设置 → 学习数据管理”可以按类别清空试卷、错题、生词与收藏、讲解对话、讲解缓存，或清空全部学习记录。每次先预览条数与影响范围，再由用户明确确认。删除试卷同时删除其答案、成绩、词句标记与解析、报告及当前关联的错题，知识点统计也随之更新；删除对话同时删除消息，讲解缓存需要单独清理。清空错题本不会删除原试卷成绩，因此知识点学习统计仍会保留。

删除前自动保存 `before-delete-*.json` 恢复备份，备份失败时不删除。页面显示备份完整路径；需要撤销时，在设置页“恢复学习数据”选择该 JSON 文件。恢复会替换当前学习记录并先备份当前状态，请先检查要保留的新记录。删除前备份可以包含未交卷试卷，但只保存在后端本机目录，不通过出卷或删除 API 公开答案。AI 出题、评分或讲解请求尚未完成时，删除与恢复会被阻止；预览后数据发生变化，须重新预览。

学习数据清理保留内置教材、内置题库、ChatGPT 连接及本地请求计数。**删除前恢复副本、其他已有备份以及浏览器下载的导出文件仍保留**；页面删除不是磁盘安全擦除。需要清理这些副本时，请在资源管理器中检查对应文件后自行删除。

SQL 迁移在 `migrations/`。后续升级应新增递增版本的迁移，不能删除数据库重建。安装依赖、构建、初始化与迁移不清空学习数据。`localStorage` 仅用于界面主题，不保存学习记录或凭据。

网站已取消本地每小时和每日的模型请求次数上限，原 `STUDY_AI_HOURLY_LIMIT`、`STUDY_AI_DAILY_LIMIT` 不再生效。SQLite 仍保留近一小时和近 24 小时的尝试次数，仅作统计，失败尝试也计入。OpenAI 官方额度、权限和速率限制仍由官方执行；网站不能据本地次数推断套餐剩余量。

## 查看每次 AI 失败的具体原因

在“连接与设置”点击 **打开 AI 失败记录**，或直接进入 `http://127.0.0.1:3210/#diagnostics`。评分、标记解析、出题、讲解及授权等错误旁也有入口，可按当前试卷、操作和错误类别筛选，每页显示 20 条。

每次失败独立追加到本机 `ai_failures`，记录发生时间、错误码、具体原因、请求阶段、模型、相关试卷/题目/标记、本地业务状态与上游 HTTP 状态，以及官方返回的错误消息、Request ID、Response ID、网络原因或结果校验字段（收到时才记录）。例如收到 HTTP 200 后事件流中断，页面会同时保留上游 200、本地 502 和中断原因；不会把内容格式错误说成账号或网络问题。可展开详情并复制脱敏诊断文本。官方错误消息与细节有长度边界，过长信息会截断；不保存完整学习输入、完整生成内容、授权头或令牌。

重试成功或再次失败都不会覆盖此前失败。首次升级仅按原时间补录旧版当时仍保存的最后一次评分/标记错误，明确标记为旧快照；旧版没有保留的逐次错误和 GPT 原始消息无法补回。重启发现 pending 请求时记录中断；关联试卷或对话被删除时，对应诊断一并删除，清空全部学习数据也清空全部诊断，删除前备份仍可恢复。新格式学习备份包含失败历史。

## 外部调用使用哪种额度

当前网站通过官方 Continue with ChatGPT / Use your ChatGPT plan 授权，使用 **Codex / ChatGPT Work 额度**。官方目前提供的这条外部应用接入方式不能选择普通 Chat 对话额度；选择较轻的模型可以影响消耗，但不改变额度来源。见 [Sign in with ChatGPT 官方说明](https://learn.chatgpt.com/docs/sign-in-with-chatgpt) 和 [支持的模型调用方式](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)。

连接应用不会增加独立额度；是否允许应用在套餐额度用完后使用购买的点数，取决于 ChatGPT 官方使用量设置。请在该页面查看应用使用情况和相关开关。本网站没有新增独立支付渠道，也不会用普通 Chat 网页的内部接口模拟外部调用。需要减少判卷消耗时，可选择“常规判卷”，让选择、阅读选择与填空在本机完成评分。

## 常见错误

| 情况 | 处理 |
| --- | --- |
| 只登录成功，套餐未授权 | 点击重新授权，授予套餐权限 |
| state/nonce 不匹配，回调过期 | 回到连接页重新开始；不重放旧回调 |
| 令牌过期或授权撤销 | 刷新失败后提示重新连接，不循环登录 |
| 账号/工作区不符合资格 | 根据实际错误检查所选账号或工作区；不无限重试 |
| 套餐/应用用量达到上限 | 打开“管理 ChatGPT 使用量”；不猜测恢复时间 |
| 临时服务不可用 | 稍后手动重试，保留学习与部分评分 |
| 流中断、失败、不完整或 JSON 无效 | 请求失败；部分文本不视作完成，不保存为完整试卷 |
| 内置题池无法满足条件 | 调整条件或在授权后改用 AI 出卷 |
| 生词、错题或薄弱点暂时为空 | 先积累相应记录，或选择普通出卷；不会悄悄改成综合题 |
| AI 重新出题后仍含重复题目 | 本套未保存；扩大题目范围、调整知识点，或稍后手动重试 |
| 删除预览后数据已变化或预览过期 | 重新打开删除预览，检查新的影响范围后确认 |
| 正在出题、评分或讲解时删除/恢复被阻止 | 等当前请求结束后再操作 |
| 考试未完成时导出被阻止 | 先交卷并完成评分，然后导出学习备份 |
| 端口占用 | 更改 PORT；继续使用 `127.0.0.1` |
| npm 命令在当前环境不存在 | 使用 pnpm 或 Windows 启动脚本 |

模型请求严格遵循此授权流程：`GET https://api.openai.com/v1/models`；`POST https://api.openai.com/v1/responses`；`store:false`、`stream:true`、上下文作为 `input` 数组，使用 developer 消息。没有 `system` 消息、`temperature`、`max_output_tokens` 或 `previous_response_id`。只在收到 `response.completed` 且业务校验通过后记为完成。模型返回的失败、额度错误或断流都有独立处理。

## 验证记录与 GitHub

实际测试结果和待验证内容见 [verification/results.md](verification/results.md)。自动化网络响应使用模拟 transport，和真实 OAuth/套餐调用分开报告。真实验证必须由用户亲自登录并完成调用；没有令牌或未调用成功时不能声称已验证。

GitHub 只保存源代码、锁文件、迁移、原创种子内容和文档。`.gitignore` 排除数据库/WAL/SHM、学习文件、认证、环境文件、日志、缓存、导出、备份、依赖及构建产物。推送前运行 `pnpm audit:files` 检查已跟踪路径、工作目录、暂存区与可达提交历史中的疑似令牌。如果历史中发现凭据，停止推送并先处理历史和撤销凭据。

当前项目的 `origin` 指向上述个人公开仓库。后续更新在本地保存代码后，先检查待发布内容再推送：

```powershell
pnpm audit:files
git push origin main
```

另一台电脑可通过 Git 下载源码，再按前面的安装说明安装依赖并启动：

```powershell
git clone https://github.com/DowneWasDreaming/japanese-study.git
cd japanese-study
```

只下载和运行公开源码无需 GitHub 写入权限，向仓库推送修改则需要相应账号认证。如果远端已有新提交，先 fetch 并整合历史，不能强制推送覆盖。不要把本机 `.local` 或导出文件加入提交。源码仓库不包含当前电脑的学习数据；换电脑时，可用网站的学习备份导出及恢复功能转移个人记录，并在新电脑重新连接 ChatGPT。
